
# EnergyShare Project Overview

EnergyShare is a prototype web platform designed
for Tunisian households that produce or consume
solar energy.

The project is motivated by electricity supply
challenges, including summer power interruptions
in Tunisia.

Households can record solar production and
electricity consumption, calculate energy surplus,
and participate in simulated energy exchanges.

EnergyShare does not physically transfer electricity
or process real payments.

The application uses React, an API Gateway,
and independently deployed backend microservices.
